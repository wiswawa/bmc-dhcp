点「开始探测」
  • 地址不是 192.168 也没关系：这台机器的静态 IP 可能是上一家单位留下的任何值，下面五招覆盖不同情况
  • 最稳的一招：让机器自己喊 —— 点开始后 把 BMC 断电重启，它上电时会发 gratuitous ARP / ARP 探测 / DHCP，二层广播，被动侦听直接听到它的地址，不需要知道任何网段
  • 先试常见出厂地址：几十个包、1 秒出结果，命中率最高（iDRAC 192.168.0.120、iBMC 192.168.2.100、XCC 192.168.70.125 之类）
  • IPv6/广播探测：跟它 IPv4 配成什么完全无关。拿到 link-local 就能用 https://[fe80::…] 打开管理页
  • 扫大网段：真不知道就填 192.168.0.0/16，会分 128 批扫完，能随时停；跨不出 /16 才有意义
  • 网线真的插在这个口上了吗（顶上的链接状态要 active）
  • 地址可能是任何值：试试 192.168.0.0/16，或者断电重启 BMC 让它自己喊一遍
  • 交换机/AP 做了端口隔离，广播过不去：一根线直连最稳
  • BMC 的网口没启用，或者机器还没上电
