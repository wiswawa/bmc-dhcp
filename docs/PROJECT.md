# BMC DHCP — 项目文档

更新：2026-11-21；当前版本：1.9.0 Beta。

## 目标

Mac 通过以太网卡直连新服务器 BMC，或接入隔离管理交换机，为已启用 DHCP 的 BMC 分配临时 IPv4 地址，让用户能打开管理页面。默认 Mac 地址 `10.99.0.1/24`，地址池 `.100–.200`，租期 300 秒。

## 产品范围

- 原生 AppKit / WKWebView 窗口，随包运行时，不依赖用户安装 Python、Homebrew 或 Chrome。
- 指定单网口、短租约、MAC 粘性地址、实时租约与日志、厂商识别、管理入口及诊断。
- 静态 BMC 的本地链路发现与用户指定范围扫描；不承诺发现所有静默设备。
- 变更网口前保存原配置；备份失败拒绝修改；恢复失败保留记录并可重试。
- 仅监听本机环回地址的控制台，管理员权限限于网络后台。
- 不提供 BMC 登录、固件修改、NAT、互联网共享、PXE 或 TFTP。

## 生命周期

1. 原生窗口以普通用户启动，通过系统授权拉起后台。
2. 后台从受 TCC 影响的目录启动时使用 Application Support 运行时副本。
3. 本地令牌握手成功后加载控制台；打开界面本身不启动 DHCP。
4. 用户选网口并启动，验证参数、处理遗留恢复记录、原子保存备份后才变更网口。
5. DHCP 租约确认后异步识别管理服务；识别失败不阻塞 DHCP。
6. 停止或退出时关闭引擎并尝试恢复；界面失联保护默认 120 秒。无法恢复时保留原始记录。

## 工程结构

详细模块、并发与信任边界见 [架构](ARCHITECTURE.md)。CLI、GUI 共用 Session 和纯 DHCP 状态机；平台差异集中在网口与传输层。

Python 要求 3.11+；原生 App 最低部署版本 macOS 13。当前本地构建/验证为 Apple Silicon，Windows 入口保持实验状态。版本号由 `src/bmcdhcp/__init__.py` 单一维护。
